📌 FASE 1: PREPARAÇÃO (2 min)

□ Baixa os arquivos da pasta "financeiro-vercel"
  → Vai em /mnt/user-data/outputs/financeiro-vercel
  → Clica em qualquer arquivo → "Download"
  → Extract no seu PC (Downloads ou onde preferir)

□ Abre terminal NA PASTA dos arquivos
  Windows: Clica direito na pasta vazia → "PowerShell aqui"
  Mac: Clica direito → "New Terminal at Folder"
  Linux: Clica direito → "Open Terminal Here"

□ Entra na pasta
  $ cd financeiro-vercel

□ Verifica que tá tudo
  $ ls
  (Deve aparecer: index.html, vercel.json, package.json, etc)

STATUS: ✅ Arquivos prontos na máquina

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

📌 FASE 2: GITHUB (4 min)

□ Cria repo novo
  → https://github.com/new
  
  Preenche:
  - Nome: financeiro-carteira
  - Descrição: Controle financeiro com OCR de recibos
  - Público: ✓
  - Initialize: deixa desmarcado
  
  → Clica "Create repository"

□ Volta no terminal e roda estes comandos (um por um):

  $ git init

  $ git add .

  $ git commit -m "Initial commit: Carteira financeiro"

  $ git branch -M main

□ Vai em GitHub, clica "<> Code" (botão verde)
  → Copia a URL (tipo: https://github.com/SEU-USER/financeiro-carteira.git)

□ Volta no terminal e cola:

  $ git remote add origin [COLA-A-URL-AQUI]

□ Final:

  $ git push -u origin main
  
  (Pode pedir senha/token — preenche e pronto)

STATUS: ✅ Código no GitHub

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

📌 FASE 3: VERCEL (8 min)

□ Vai em: https://vercel.com

□ Loga (com GitHub é mais fácil)

□ Clica "Add New" → "Project"

□ Seleciona "financeiro-carteira" (vai aparecer lá)

□ Clica "Import"

□ Vercel detecta tudo automático (vercel.json)

□ Clica "Deploy" (botão grande lá embaixo)

□ Espera 1-2 minutos...

□ Pronto! URL aparece:
  
  https://financeiro-carteira.vercel.app
  
  Clica e testa!

STATUS: ✅ Site LIVE na internet!
